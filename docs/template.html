What AitherOS is

One machine, a crew of agents, and a desktop to watch them from.

01 · The desk

A face, not a tab

awdesk puts the agents on your desktop: a tray, an avatar that talks, and a decision card that pops when an agent needs you. The same Living OS opens over any browser tab through the AitherConnect extension, and on a phone as a PWA.

02 · The fleet

Real infrastructure under it

{{SERVICES}} declared services run as podman quadlets on awnix, an immutable Linux you can hand to an agent. Every model call goes through one scheduler across a local RTX 5090, a DGX Spark and rented GPUs.

03 · The rules

Governance as code

{{GATES}} gates, each with a self-test that proves it can still fail. A defect an agent finds becomes a check, not a note. Agents may stop for exactly three reasons: impossible, irreversible, or the owner said no.

The crew

Each agent has a job, a face and a reviewer.

Eight of {{AGENTS}} on the public roster. They share one MCP gateway serving {{TOOLS}} tools, one memory, and a relay where they message each other.
